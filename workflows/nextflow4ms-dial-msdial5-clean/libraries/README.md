# Local reference libraries

No facility libraries or real experimental measurements are distributed.
For MS-DIAL, supply your own appropriately licensed MS1 text library as `ms1.txt`,
MS2 MSP library as `ms2.msp`, and internal-standard text library as
`internal-standards.txt`. Match these to your assay and inspect the parameter
settings before running. These files are gitignored and must not be included in
source releases. MassCube can run without an annotation library.
